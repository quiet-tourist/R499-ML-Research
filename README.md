## **Machine Learning Research — R499**

This repository documents my independent undergraduate study in machine learning and deep learning at Indiana University East.
The project is structured as a progression through increasingly complex models. Each stage focuses on implementing and evaluating a working model in Python/PyTorch while developing an understanding of the mathematics and computational ideas underlying it. The project does not focus on statistical analysis of the data. 

# **Models**

**01 — Linear Regression**\
Multiple linear regression using a real-estate valuation dataset. Implements data splitting, feature scaling, mini-batch training with stochastic gradient descent, validation, and testing in PyTorch.

**02 — Logistic Regression**\
Binary classification using the Wisconsin Diagnostic Breast Cancer dataset. Adds stratified sampling, binary cross-entropy loss, model-selection using validation performance, and confusion-matrix analysis.

**03 — Deep Neural Network**\
Multiclass classification of dry-bean varieties using a feed-forward neural network. Extends the workflow to multiclass cross-entropy, hidden-layer activation, best-weight selection, and multiclass confusion-matrix evaluation.

Upcoming.

Additional model families will be added as the independent study progresses.

# **Purpose**

This repository is primarily a learning record rather than a collection of production ML applications. The models are intentionally implemented in a relatively explicit manner so I can understand the training process, model behavior, and evaluation workflow rather than abstracting those steps.
